# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary: people tracking menstrual cycles who prefer a calm, metaphor-led daily check-in over clinical dashboards. Use scene: quiet personal moments on phone (morning / evening), soft ambient light.

## Product Purpose

月潮 (MoonWave) helps users feel and record their cycle as tides — phase awareness, light daily logging, observation, short mindfulness, and gentle exploration — so they can find their own rhythm.

## Positioning

Cycle tracking through a coastal tide metaphor (退潮 / 涨潮 / 满潮 / 平潮) with paper-craft visual identity, not medical-chart UI.

## Capabilities

- Home tide dial with phase day and quick metrics
- Daily status / observation logging
- Mindfulness bay (short breathing practices)
- Explore islands (education / unlock metaphor)
- Profile / streak / settings

## Terminology

- Product name: 月潮 / MoonWave
- Tide phases map to cycle phases
- Tabs: 首页 / 观察 / 正念 / 探索 / 我的

## Brand Commitments

- High-key light blue paper-relief / origami wave aesthetic (user-approved comps)
- Chinese-first UI copy
- Preserve existing features and navigation; redesign is visual world replacement

## Constraints

- Mobile phone-frame web app (Vite + React)
- Existing Phosphor icons acceptable unless replaced
- Day/night mode tokens exist; day mode is primary craft target for this redesign

## Open Decisions

- Night mode paper treatment: keep readable dark paper variant, secondary to day
